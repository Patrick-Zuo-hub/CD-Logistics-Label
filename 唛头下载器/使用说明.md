# 物流单据批量下载器

支持两类下载，页面顶部 Tab 切换：

- **下载唛头**：调 `getOutMarkPdf`，每单一个 PDF，按单号命名（`CD2607200276.pdf`）。
- **下载 POD**：调 `getlocusinfo` 查轨迹，提取其中的 `pics`（签收附件/照片）下载，按单号命名（单个附件 `CD2607200276.jpg`，多个则 `CD2607200276_1.jpg`、`_2.jpg`…）。

唛头接口使用 `http://newapi.ywcd56.com/openapi/getOutMarkPdf`，兼容直接返回 PDF、JSON `path` 中的下载地址、Base64 PDF 和 Base64 data URI。唛头的相对下载地址也从新域名下载。POD 轨迹接口仍使用原域名。

## 使用步骤

1. 打开 `env.doc`，填写物流商提供的 Client ID 和 Secret：
   - `CLIENT_ID=` → 请求头 x-api-key
   - `CLIENT_SECRET=` → 请求头 token
2. 双击 `启动.command`（首次会自动安装依赖），浏览器自动打开页面。
3. 选择「下载唛头」或「下载 POD」标签，二选一提供单号：
   - **上传 Excel（.xlsx）**：表头为 `waybill_num` 或含“单号”的列会被识别；无表头时取第一列。
   - **文本框粘贴**：换行、逗号、空格、顿号、分号分隔均可。
4. 下载完成后文件已按单号命名，唛头存 `唛头PDF` 文件夹、POD 存 `POD` 文件夹，也可点页面链接打包下载 zip。

> POD 说明：签收附件来自轨迹接口的 `pics` 字段。若某单尚未签收/无附件，会显示“无POD附件”，其余单号照常下载。

## 大批量：自动分批

可以一次上传/粘贴**全部单号**，页面会自动**每 10 个一批**顺序查询，实时显示进度条与逐单结果，最后在浏览器端把所有文件合并成一个 zip 供下载。因为每次请求只处理 10 单，单次响应很快，不会因单量大而超时报错。若某一批网络失败，只影响该批，其余照常，失败单号会在末尾汇总方便重查。

> 每批数量默认 10，可在 `app.py` 顶部前端脚本里的 `BATCH_SIZE` 调整。

## 局域网共享

启动后终端会显示「局域网访问」地址（如 `http://192.168.x.x:8756`），把该地址发给同一网络的同事，即可在他们的浏览器中同时使用。每个人的下载结果互相独立；所有 PDF 同时也会保存到主机的「唛头PDF」文件夹。若同事无法访问，请检查 Mac 的「系统设置 → 网络 → 防火墙」是否放行 Python。

## 部署到公网（Vercel，凭证不公开）

原理：Client ID / Secret 只在**后端**使用，浏览器全程看不到。部署时凭证填在 Vercel 后台，
以加密环境变量存储，不进代码、不上传 GitHub，同事只用网页、拿不到凭证。

**一次性步骤：**

1. **代码传到 GitHub 私有仓库**
   - 在 github.com 新建一个 **Private** 仓库
   - 把「唛头下载器」文件夹里的内容传上去
   - `.gitignore` 已配置为排除 `env.doc`，凭证文件不会被上传（务必确认）

2. **用 Vercel 部署**
   - 打开 vercel.com，用 GitHub 账号登录 → New Project → 选中该仓库 → Deploy
   - 项目已含 `vercel.json` / `requirements.txt` / `api/index.py`，Vercel 会自动识别为 Python 应用

3. **填写凭证（关键）**
   - Vercel 项目页 → Settings → Environment Variables，添加两条：
     - `CLIENT_ID` = 你的 Client ID（x-api-key）
     - `CLIENT_SECRET` = 你的 Secret（token）
   - 保存后到 Deployments 里点 Redeploy 使其生效

4. **分享**
   - Vercel 给出的网址（如 `https://xxx.vercel.app`）发给同事即可，随时随地用，无需局域网、无需你的电脑

**注意事项：**
- 目前公网版没有访问密码——任何知道网址的人都能用，会消耗你的 API 额度。如需加一道共享密码，告诉我即可加上。
- Vercel 免费版单次函数执行约 10 秒上限，单号很多时可能超时；量大建议用方案 B（云服务器）或分批上传。
- 公网版不在服务器保存 PDF，改为处理完直接让浏览器下载 zip。
